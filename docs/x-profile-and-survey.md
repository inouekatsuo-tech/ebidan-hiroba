## 4. 運用メモ（アカウントを育てるために）
- 1日の目安：自分の投稿1〜2本＋他のファンの投稿への「中身のある」リプ5〜10件
- 他の人の投稿へのリプにサイトURLを貼らない（宣伝アカウント扱いされる）。URLはプロフと固定ツイートに置き、リプは会話に徹する
- 公式アカウントやメンバー本人の投稿へのリプで宣伝はしない
- 未成年とのDMはしない。DMが来ても、やり取りは公開のリプかサイトの運営あてへ誘導
- 投稿のネタ：サイトの更新報告 / 今日の出演まとめ / つくった理由 / 親目線の推し活あるある / アンケート結果の共有
- ハッシュタグは「#EBiDAN」とグループ名・ファンの呼び名（#みるきーず #8号車 など）に絞る。「〜と繋がりたい」系のタグは使わない（探している人の目的が違うため、情報の投稿では逆効果）
- 画像つきの投稿のほうが伸びる（サイトの画面を1枚貼る）
